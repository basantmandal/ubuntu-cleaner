# Security Policy

**Ubuntu Cleanup** — A Bash system cleanup utility for Ubuntu/Debian Linux

---

## Supported Versions

Only the latest release receives security updates. No LTS or backport support is provided for older versions.

| Version  | Supported               |
| -------- | ----------------------- |
| latest   | :white_check_mark:      |
| < latest | :x:                     |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Ubuntu Cleanup, please send an email to [support@basantmandal.in](mailto:support@basantmandal.in).

**Do not open a public GitHub issue** — vulnerabilities must be reported privately so they can be addressed before public disclosure.

All security vulnerabilities will be promptly reviewed and addressed.
